# Omni 接单插件设计确认

## 目标

在不改变现有豆包接单流程的前提下，增加独立的 Omni 接单插件。两个插件共用同一张飞书兼职表和同一套服务端锁，但每个浏览器插件一次只持有一个订单。

## 已确认流程

1. Omni 插件仅在 Google Flow 页面显示右侧悬浮面板。
2. 接单时服务端写入 `制作平台 = Omni`；豆包插件写入 `制作平台 = 豆包`。
3. Omni 插件继续提供提示词和图片复制，不自动监听生成结果。
4. 操作者手动粘贴公开的 Flow 单视频分享链接。
5. 服务端解析分享 UUID，从 Google Flow 官方视频接口读取 MP4，并转存到现有 Cloudflare R2。
6. 只有 R2 公网链接验证可读后，服务端才把 `视频地址` 回填飞书并将任务标记为 `已完成`。
7. 转存失败时任务保持 `接单中`，保留分享链接，可重试或手动释放；不增加失败次数。
8. 释放任务时清空 `制作平台`，已完成任务保留平台信息。

## 安全边界

- 只接受 `https://labs.google/fx/tools/flow/shared/video/<UUID>` 格式的链接。
- 完成和释放均校验 `record_id`、`lock_id` 与接单人，防止覆盖其他人的任务。
- R2 上传后必须通过公开 URL 可读性验证，才允许回填完成状态。
- Omni 不启用下载监听、页面视频嗅探或自动匹配。
